# Primer — capture inbox (backlog queue)

Drop terms here when you're on the phone and can't run the full workflow.
Each line under **Queue** is one concept to add later. The term name is enough
— no code, no JSON. On the laptop, running `/primer-add` (or asking Claude to
"drain the Primer inbox") turns every queued term into a full concept in
`concepts.js`, then clears the queue.

How to add from mobile (no connector needed):
1. Learn the concept in the Claude app chat as usual.
2. Open this file on github.com → edit (pencil) → add a line under **Queue**
   with the term name → commit. (The GitHub website works fine on a phone.)
